OCT feature mapper build package

Contents
- OCT_feature_mapper_v0.83.py
- build_windows.bat
- build_mac.sh
- requirements.txt

Windows
1. Install Python 3.11 or 3.12 for Windows.
2. Put all files in one folder.
3. Double-click build_windows.bat
4. When the build finishes, the executable will be in the dist folder.

macOS
1. Open Terminal in this folder.
2. Run: chmod +x build_mac.sh
3. Run: ./build_mac.sh
4. When the build finishes, the executable will be in the dist folder.

Notes
- Build the Windows executable on Windows.
- Build the macOS executable on a Mac.
- The live enface preview in this version is a further 15% larger than the previous package.
- If Windows says py is not found, install Python from python.org and tick Add Python to PATH during install.
